# Automação de Excel com Python

Projeto de automação que lê, limpa, consolida e formata planilhas Excel automaticamente, gera gráficos, agenda a execução e envia o relatório por e-mail — tudo sem intervenção manual.

## O que o projeto faz

- 🧹 **Limpeza de dados**: remove duplicatas, trata valores vazios e padroniza textos
- 📊 **Consolidação**: junta múltiplas planilhas em um único relatório
- 🎨 **Formatação automática**: cabeçalhos estilizados, formato de moeda e largura de colunas ajustada
- 📈 **Gráficos e formatação condicional**: gera gráfico de barras e destaca valores altos/baixos com cores
- ⏰ **Agendamento**: roda sozinho todos os dias via Agendador de Tarefas do Windows
- 📧 **Envio automático por e-mail**: envia o relatório final como anexo

## Tecnologias utilizadas

- Python 3.14
- pandas
- openpyxl
- python-dotenv
